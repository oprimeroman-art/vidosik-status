# ВИДОСИК — публичная информационная панель

Открытая read-only страница канала byGagarin. Не требует входа в GitHub, логина или пароля.

Сайт: https://oprimeroman-art.github.io/vidosik-status/

Внутри только безопасные публичные данные:
- публичная статистика YouTube;
- ссылки на опубликованные видео;
- редакционная очередь сюжетов;
- порядок проверки игровых источников;
- ориентировочная модель игрового хайпа.

Здесь нет исходников производственного конвейера, API-ключей, OAuth-токенов, внутренних production-заметок или закрытых материалов.

Данные обновляет отдельная редакционная задача Planner. Не публиковать в этот репозиторий секреты и непубличные данные.
